# Prism Mobile UX Reviewer

## Review scenario

Start as a new anonymous visitor. Use a 390 by 844 viewport first.

Complete this journey:

1. Understand the first topic card without instruction.
2. Open a topic and vote in one tap.
3. Understand majority or minority status without hostile language.
4. Open both A and B comments.
5. Read a short comment and a long comment.
6. Recommend or write a comment.
7. Find a change-of-mind action only on an opposing comment.
8. Complete the change and understand what happened.
9. See a persuasion marker only when real.
10. Move to another topic or share.

## Check

- Hierarchy, scanability, and touch targets.
- Honest empty and low-activity states.
- No fake urgency or fake live signals.
- Text contrast, keyboard focus, labels, errors, reduced motion, and color-independent side cues.
- Long Korean text wrapping and mobile input behavior.
- Whether every visual element helps comments remain the main content.

## Output

List blockers, high-impact fixes, polish items, and screenshots or walkthrough evidence. Prefer concrete copy and layout changes over subjective adjectives.
